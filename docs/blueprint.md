# **App Name**: EVPulse

## Core Features:

- Smart Vehicle Onboarding: Identify your EV model to automatically pull specifications including battery capacity, charging curve, and port type using an intelligent lookup tool.
- Intelligent Charging Planner: A logic tool that analyzes your route and battery levels to automatically suggest optimal charging stops, minimizing total travel time.
- Dynamic Range Mapping: Real-time integration with Yandex Maps API to provide live traffic updates and continuous updates of remaining autonomy on the map.
- Real-time Battery Dashboard: High-visibility visual progress indicators showing projected battery percentage at the destination and the next charging point.
- Filtered Charger Discovery: Access a comprehensive map of charging stations specifically filtered for your car's compatibility (e.g., GB/T for Chinese models).
- History and Fleet Sync: Save and sync your favorite routes and vehicle parameters across multiple mobile devices using a centralized database.
- Precision Efficiency Analytics: Display clear technical metrics such as consumption rate (kWh/km) relative to your current driving style and conditions.

## Style Guidelines:

- Primary color: Electric Indigo (#5E5EED), selected for a tech-focused, high-performance aesthetic that provides excellent visibility in dark mode.
- Accent color: Lucid Sky Blue (#3099E8), providing contrast for highlights and CTAs to evoke a sense of clean energy.
- Background: Deep Midnight Blue (#0F0F14), a low-reflection dark base perfect for night-time driving and automotive cockpit integration.
- A pairing of 'Space Grotesk' for technical headlines and navigation headers to convey a futuristic feel, and 'Inter' for body text and telemetry data to ensure legibility.
- Minimalist, high-contrast line icons designed for instant recognition while driving, emphasizing car components and electrical nodes.
- An Apple-inspired card-based layout featuring oversized touch targets for safety and a distraction-free full-screen map interface.
- Smooth, accelerated transitions for telemetry data updates and route re-calculations to provide immediate feedback to the driver.
