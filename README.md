# EVPulse | Умная навигация для Электромобилей в Беларуси

Интеллектуальное планирование маршрутов и управление данными электромобиля с помощью ИИ.

## Основные функции
- ✨ **ИИ-Профиль:** Быстрая настройка автомобиля через текстовый запрос (марка, модель, год).
- 🗺️ **ИИ-Навигатор:** Поиск оптимальных маршрутов с учетом остатка заряда, типов коннекторов и ваших предпочтений (например, зарядки Malanka рядом с кафе).
- 📊 **История и Аналитика:** Отслеживание поездок и эффективности расхода энергии.
- 🔋 **Мониторинг батареи:** Визуализация текущего состояния заряда и запаса хода.

## Как запустить проект локально

### 1. Требования
- Node.js (версия 18 или выше)
- npm или yarn

### 2. Установка
```bash
npm install
```

### 3. Настройка окружения
Для работы ИИ-функций (Genkit/Gemini) вам потребуется API-ключ Google AI. Создайте файл `.env` в корневой директории и добавьте:
```env
GOOGLE_GENAI_API_KEY=ваш_ключ_здесь
```

### 4. Запуск
```bash
npm run dev
```
Приложение будет доступно по адресу [http://localhost:9002](http://localhost:9002).

## Стек технологий
- **Framework:** Next.js 15 (App Router)
- **AI Tooling:** Genkit + Google Gemini
- **Styling:** Tailwind CSS + ShadCN UI
- **Icons:** Lucide React
- **Fonts:** Space Grotesk (заголовки) & Inter (текст)
