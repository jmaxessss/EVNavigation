
# EVPulse | Умная навигация для Электромобилей в Беларуси

Интеллектуальное планирование маршрутов и управление данными электромобиля с помощью ИИ.

## Технологии и Алгоритмы
Проект использует современные подходы к обработке данных:
- **NLP (Natural Language Processing):** Модели Google Gemini для интерпретации запросов пользователя на естественном языке.
- **Инструментальное сопоставление (Tool Calling):** Алгоритмы Genkit для автоматического поиска технических характеристик авто.
- **Контекстное планирование:** Эвристические алгоритмы выбора зарядных станций Malanka на основе многофакторного анализа (время, тип разъема, инфраструктура).

## Установка и запуск
1. Установите зависимости: `npm install`
2. Добавьте `GOOGLE_GENAI_API_KEY` в `.env`
3. Запустите: `npm run dev`

## Это приложение — PWA (Progressive Web App)
Вы можете установить его на Android через Chrome ("Добавить на главный экран"), и оно будет работать как нативное приложение.
