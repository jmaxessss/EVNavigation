
# EVPulse | Умная навигация для Электромобилей в Беларуси

Интеллектуальное планирование маршрутов и управление данными электромобиля с помощью ИИ.

## Это приложение — PWA (Progressive Web App)
Это означает, что вы можете использовать его как обычное приложение на Android или iOS без необходимости скачивания из App Store или Google Play.

### Как установить на Android:
1. Откройте сайт приложения в **Google Chrome**.
2. Нажмите на три точки (меню) в верхнем правом углу.
3. Выберите **"Добавить на главный экран"** или **"Установить приложение"**.
4. Теперь EVPulse появится в вашем списке приложений с собственной иконкой и будет открываться без интерфейса браузера.

## Основные функции
- ✨ **ИИ-Профиль:** Быстрая настройка автомобиля через текстовый запрос.
- 🗺️ **ИИ-Навигатор:** Поиск маршрутов с учетом зарядок Malanka и ваших предпочтений.
- 🔋 **Мониторинг:** Визуализация заряда и запаса хода.

## Как запустить проект локально
1. Установите зависимости: `npm install`
2. Добавьте `GOOGLE_GENAI_API_KEY` в `.env`
3. Запустите: `npm run dev`

Проект доступен по адресу [http://localhost:9002](http://localhost:9002).
